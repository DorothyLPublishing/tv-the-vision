# Create The Vision™ Landing Page

A mobile-first, single-page barber landing page based on the approved executive urban concept.

## Current status

The structure, styling, mobile navigation, service cards, portfolio placeholders, contact area, and demo booking form are complete.

## Replace before launch

Open `index.html` and replace:

- `(918) 555-0123`
- `info@createthevision.com`
- Tulsa location wording
- Business hours
- Social media `#` links
- Service prices shown as `$—`
- Owner portrait placeholder
- Action-photo placeholder
- Three before-and-after transformation placeholders
- Review placeholders

## Booking

The form currently demonstrates the client experience but does not transmit data.

Connect it to one of the following:

- TV's existing booking link
- Square Appointments
- Calendly
- Google Form
- Formspree
- Netlify Forms

For the lowest-maintenance launch, replace the form with one large button linked to the booking service TV already uses.

## Local preview

Open `index.html` directly in a browser.

## Netlify deployment

1. Sign in to Netlify.
2. Drag the entire `create-the-vision-landing-page` folder into the manual deployment area.
3. Add the final domain or use the free Netlify URL.
4. Test every link on a phone.

## Image guidance

Use optimized WebP or JPEG images. Recommended maximum width:

- Hero portrait: 1200 px
- Action photo: 1000 px
- Before-and-after images: 800 px each

Keep each image under approximately 300 KB where practical.
